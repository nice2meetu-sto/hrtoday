# 인력현황 대시보드 (서울관광재단 HR)

기준일(그 날짜)의 **인원 현황**, **현재 사용 중인 제도**, **앞으로 사용할 제도**를
한눈에 보고, 인사발령 도래 일정을 **캘린더 + D-day**로 확인하는 단일 HTML 웹앱입니다.

- **단일 `index.html` + 바닐라 JS** (프레임워크·빌드 도구 없음)
- 데이터는 **GET 전용 Apps Script JSON API**를 `fetch()`로 호출
- GitHub Pages 등 정적 호스팅에서 그대로 동작 (브라우저 저장소 미사용)

## 구성 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 대시보드 본체. 상단 `SCRIPT_URL`만 바꾸면 실데이터로 동작 |
| `Code.gs` | 구글시트에 붙여넣는 Apps Script (GET JSON API) |

> `SCRIPT_URL`이 비어 있으면 내장 **샘플 데이터**로 화면이 그대로 열립니다.
> URL을 채우는 순간 구글시트 실데이터를 불러옵니다.

## 탭 구성

1. **기준일 현황** — KPI 4칸(재직 / 휴가·휴직 중 / 단축 중 / 임박 일정 30일) + 월 캘린더 + D-day 리스트
2. **제도별 조회** — 대분류(단축/휴가/휴직) → 세부 제도 칩, 현재 사용 중 / 사용 예정 2단, 명단 CSV
3. **전체 명단** — 기준일 기준 전 인원 표(검색·상태 필터·CSV)
4. **타임라인** — 제도 보유자 간트(기준일 −3개월 ~ +12개월), 기준일 세로선 기준 현재/예정 구분

기준일을 바꾸면 모든 탭이 그 날짜 기준으로 다시 계산됩니다.

## 데이터 모델 (구글시트 두 시트)

**인원 시트** (1인 1행)
`사번 · 사원명 · 부서 · 직급 · 고용형태 · 입사일 · 퇴사일`

**제도 시트** (제도 1건당 1행)
`사번 · 제도 · 시작일 · 종료일 · 상세 · 비고`

- 날짜는 `YYYY-MM-DD` 문자열. `퇴사일`·`종료일`은 빈칸 가능.
- 대분류(단축/휴가/휴직)는 제도 이름에서 자동 판별 — 별도 컬럼 불필요.

## 설치 / 배포

### 1) 구글시트 + Apps Script

1. 구글시트에 `인원`, `제도` 두 탭을 만들고 위 헤더대로 데이터를 채웁니다.
2. **확장 프로그램 > Apps Script**를 열고 `Code.gs` 내용을 붙여넣어 저장합니다.
3. **배포 > 새 배포 > 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
4. 발급된 **웹 앱 URL**을 복사합니다.

### 2) index.html 연결

`index.html` 상단의

```js
const SCRIPT_URL = ""; // ← 배포된 Apps Script 웹앱 URL
```

에 복사한 URL을 붙여넣습니다.

### 3) GitHub Pages 게시

1. 이 저장소의 **Settings > Pages**로 이동
2. **Build and deployment > Source: Deploy from a branch**
3. Branch를 게시할 브랜치(`main` 또는 해당 브랜치) / 폴더 `/ (root)`로 설정 후 Save
4. 잠시 뒤 `https://<org>.github.io/hrtoday/` 에서 열립니다.

## 점검 체크리스트

- [x] 기준일을 옮기면 재직/휴직/퇴사/입사예정 상태가 규칙대로 자동 변경
- [x] 한 사람의 임신기단축 → 산전후휴가 → 육아휴직이 타임라인 한 줄에 막대 3개, 현재/예정 구분
- [x] 제도별 조회에서 쓰는 사람이 없는 세부 제도 칩은 표시되지 않음
- [x] 전체 명단 퇴사 필터 시 퇴사자만, 제도 태그 오버에 기간 툴팁
- [x] `SCRIPT_URL`만 바꾸면 실데이터로 동작, GitHub Pages에서 그대로 열림
